# Builder V13 — Universal Creation Engine Master Spec

## Product promise
Describe anything. Builder understands the intended outcome, asks only high-value questions, creates a blueprint, assembles the right specialists, uses relevant resources and capabilities, builds, tests, verifies, secures, optimizes and prepares the correct kind of release.

## V13 north star
Builder is an **AI Creation Operating System**, not merely an AI coding assistant.

The core lifecycle is:

IDEA → UNDERSTAND → DISCUSS → PLAN → CREATE → EDIT → TEST → VERIFY → SECURE → OPTIMIZE → SHIP → OPERATE → IMPROVE

Principles:
- Warm off-white / bone foundation
- Deep ink typography
- Electric blue accent
- Strong whitespace
- Thin borders
- Restrained shadows
- Sophisticated states
- Responsive layouts
- Keyboard/focus support
- Reduced-motion support
- Cinematic but restrained micro-interactions

## Shipping / publish readiness
The repository contains the frontend, legal pages, SEO files, security headers, Supabase schema/functions/migrations, payment infrastructure hooks, test scripts and deployment configuration.

Before a real production launch, the owner must still configure their own:
- Supabase project URL and publishable key
- production site/domain
- authentication redirect settings
- Supabase migrations/functions/secrets
- supported AI provider credentials
- payment merchant credentials if payments are enabled
- deployment host/domain/DNS
- analytics measurement ID if desired

Those are environment/provider-specific operations and are intentionally not hard-coded into the repository.

## V13 implementation honesty
V13 is a significantly upgraded, publish-oriented frontend/workspace foundation. Some enterprise/runtime capabilities—such as durable background workers, full browser sandbox infrastructure, complete cloud project persistence, true realtime collaboration, complete production deployment orchestration, and fully autonomous multi-agent execution—require corresponding backend/runtime services. The UI and architecture surfaces should not be mistaken for those services being fully deployed.
