## What is simulated

- Sandbox: isolated project-only filesystem, network-disabled execution contract.
- Browser testing: deterministic DOM/resource/interaction/responsive/security checks.
- Synthetic users: repeatable user journeys.
- Multi-agent: specialist queue, execution, handoff and completion traces.
- Cloud persistence: Supabase-shaped persistence adapter.
- Collaboration: event stream adapter.
- Deployment: verification-gated deployment adapter with rollback token.
- Desktop/mobile compilation: target build adapter contract.
- Transformation: requirement/resource/runtime mapping followed by verification.
- Self-healing: failure classification, repair, retest and regression verification.

External credentials, native build farms, real browser infrastructure and production deployment providers still need their live adapters/credentials before they can honestly be called production-green.
